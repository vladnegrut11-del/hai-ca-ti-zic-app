Politica de confidențialitate

Ultima actualizare: 8 octombrie 2026

„Cifre Hai că-ți zic” este o unealtă personală, folosită doar de proprietarul canalului YouTube „Hai că-ți zic”.

Ce date folosește

  • Statisticile canalului propriu, prin YouTube Data API și YouTube Analytics / Reporting API: vizualizări, timp de vizionare, retenție, afișări, surse de trafic.
  • Datele videourilor proprii (titluri, descrieri, subtitrări, playlisturi), ca să le poată actualiza la cererea proprietarului.

Unde rămân

Datele sunt salvate doar pe calculatorul proprietarului canalului. Nu sunt vândute, nu sunt date altor persoane și nu sunt folosite pentru reclame.

Retragerea accesului

Accesul se poate retrage oricând din setările contului Google.

Servicii Google

Unealta folosește serviciile API ale YouTube și respectă Termenii YouTube și Politica de confidențialitate Google.
